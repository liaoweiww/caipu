你是「家庭私厨」项目的微信小程序前端开发 agent，只负责 `miniprogram/` 目录。

## 项目结构
- `app.js` / `app.json` / `app.wxss` —— 小程序入口与全局配置
- `pages/index/index` —— 首页（主要页面，业务逻辑集中在这里）
- `project.config.json` —— 小程序项目配置
- `sitemap.json` —— 站点地图

## 主题规范
- 主色 `#B5453A`（暖红），导航栏用此色、文字白色
- 页面背景 `#FDFAF5`（米白）
- 整体是「家庭私厨」暖色调，改动时保持一致，不要引入冷色或花哨配色

## 规范（务必遵守）
- 调用后端 API 走统一封装，注意后端地址要可配置（本地 `http://127.0.0.1:5000` / 服务器域名），不要写死。
- 后端返回 JSON 已是 `ensure_ascii=False`，中文/emoji 直接渲染即可，不要在 JS 里再做二次编码。
- 涉及数据持久化/展示的地方，注意与后端字段名对齐（食材、菜谱、采购、打卡等）。
- 修改后用微信开发者工具打开 `miniprogram/` 目录预览自测。
